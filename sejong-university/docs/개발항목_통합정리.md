# 1~3차년도 개발 항목 통합 정리

1·2·3차년도 제안서와 연차보고서에 나온 세종대학교 개발 항목이 이 저장소의 어느 폴더로 들어갔는지 정리한 문서입니다.

통합할 때 따른 기준은 다음과 같습니다.

- 후속 차년도에서 같은 목적으로 발전한 기능은 최신 구현 하나만 둡니다.
- 후속 문서에 이름이 없다는 이유만으로 이전 기능을 지우지 않습니다. 대체되지 않은 기능은 유지합니다.
- 이전 방식이 최신 방식의 효과를 보여 주는 비교 기준으로 필요하면 기본 경로와 분리해서 남깁니다.

항목별 세부 내용은 각 폴더의 README에 있습니다. 정리 전에 각 팀이 따로 만든 대응표는 [docs/history](history)에 원본 그대로 두었습니다.

## 가. 단말/계층형 연합 학습 실험을 위한 시뮬레이션 환경

### [1-1 계층형 연합학습 시뮬레이터](../1_simulation/1-1_hierarchical_fl/README.md)

- (1차) 파이썬 환경 기반 단일 컴퓨터 시뮬레이션 환경 설계
- (2차) Flask 기반 멀티 컴퓨팅 시뮬레이션 환경 구현
- (3차) Flask 기반 계층적 연합학습 시뮬레이션 환경 구현

최종 구현은 3차 구조(클라이언트, Flask 엣지 서버, 전역 서버로 이루어진 3계층과 REST 통신, 게임 이론 매칭)이고, 1·2차 기능은 실행 방식으로 들어갔습니다. 1차의 단일 컴퓨터 실행에 해당하는 것은 한 프로세스 안에서 Flask REST 경로를 그대로 타는 `transport=local`, 클라이언트 학습 스레드 병렬화, 엣지 프로세스 병렬화, asyncio 비동기 엣지 호출입니다. 2차의 멀티 컴퓨팅에서는 원격 엣지 연결(`--edges`), SQLite 레지스트리, 데이터 비율과 정보 엔트로피 API, R/H 히트맵을 가져왔습니다. 2차의 단일 서버 구조는 엣지를 1개로 설정하면 그대로 재현되므로 별도 실행기를 두지 않았습니다.

### [1-2 계층형 연합학습 평가 시각화](../1_simulation/1-2_fl_visualization/README.md)

- (1차) 단일 컴퓨터 성능 모니터링 시각화 설계(지역 모델 평가, 로그, 자원 사용량)
- (2차) 시뮬레이션 모니터링(training trend, outlier detection, hyperbolic, 데이터 비율·엔트로피 heatmap)
- (3차) 매칭·알고리즘 평가 시각화(tree, 우선순위 rank, 통신 상태, 매칭 행렬, 알고리즘 비교)

1·2차 화면은 3차 대시보드 하나에 합쳤습니다. tree는 계층 구조를, hyperbolic은 통신 연결을, sankey는 트래픽을 보여 주므로 서로 대체하지 않았습니다. 1차의 자원, 로그, 모델 관계 시각화와 2차의 데이터 비율·엔트로피 화면은 독립된 화면으로 남아 있습니다.

### [1-3 보안 공격·방어 시뮬레이션](../1_simulation/1-3_security/README.md)

- (1차) 보안 시뮬레이션 시험 환경과 네트워크 비용 산출 환경 설계
- (2차) 다계층 구조의 보안 시험 시뮬레이션 환경
- (3차) 보안 시뮬레이션 환경 고도화

연차별 공격과 방어는 대상이 서로 달라서 모두 유지했습니다. 1차에서는 데이터 조작을 데이터 분포 분석으로, 모델 변조를 파라미터 통계 탐지로, 가짜 클라이언트를 인증서로 막고 시나리오별 네트워크 비용을 계산합니다. 2차는 데이터 중계 공격에 HMAC-SHA256을, 계층적 협력 공격에 K-Means를, 다단계 피싱에 2차 인증과 모니터링을 대응시켰고 One-Class SVM과 엣지·전역 2계층 방어를 더했습니다. 3차에서는 내부자 협력 공격을 내부자 모니터링으로, 모델 역추적 공격을 출력 제한, 출력 노이즈, 질의 한도로 막습니다.

### [1-4 지역 분산 컴퓨팅과 연합 컴퓨팅 비교](../1_simulation/1-4_distributed_comparison/README.md)

- (1차) 지역 분산 분석 성능 평가 시뮬레이션 설계(데이터 정제·분할, 독립 분석, Precision·Recall·F1)
- (3차) 지역 분산과 연합 컴퓨팅 비교 환경 구현과 평가

1차에서 설계한 데이터 준비, 독립 분석, 지표는 3차 비교 환경의 전처리, 실행, 평가 절차로 합쳤습니다. 데이터를 옮기지 않는 1차의 독립 분석 조건은 그대로 두었고, 3차에서 결과 공유, 재분할과 동기화, 중앙 분석까지 비교 범위를 넓혔습니다. 결과 화면은 1-2의 비교 카드를 같이 씁니다.

### [1-5 연합학습 시나리오 테스트](../1_simulation/1-5_scenario_test/README.md)

- (3차) 시뮬레이션 환경에서의 다양한 연합학습 시나리오 테스트

제안서에 있던 네트워크 지연, 참여 비율 변동, 데이터 불균형 시나리오에 엣지 서버 장애와 내부자 협력 공격 시나리오를 더했습니다. 기준 환경과 비교한 적응력 지수, 업데이트 주기, 클라이언트별 성능과 기여도를 함께 봅니다.

### [1-6 다계층 네트워크 비용 최적화](../1_simulation/1-6_network_cost/README.md)

- (2차) 다계층 네트워크 비용에 따른 최적화 기술 시뮬레이션 설계와 구현

엣지 컴퓨팅(업링크 경량화), LRU 캐시(중복 전송 방지), DAG 비용 최적 경로를 실제 Flower 메시지 전송에 적용하고 최적화 전후 비용을 비교합니다. 3차년도에 이를 대체하는 항목이 없어 그대로 유지했습니다.

## 나. 분석 속도 향상을 위한 다계층 분산 연합 분석 기술

### [2-1 연산 그래프 기반 모델 가지치기](../2_analysis_speed/2-1_graph_pruning/README.md)

- (1차) AI 모형 소규모화 기술 설계
- (2차) 고도화된 AI 모형 소규모화 기술 구현
- (3차) 연산 그래프 기반 가지치기를 활용한 소규모화 고도화

최종 구현에는 연산 그래프 생성, 노드와 엣지의 경로 중요도, 임계값 가지치기, 손실 변화에 따른 임계값 동적 조정, 연합학습 중 전역 모델 가지치기가 들어 있습니다. 2차의 BN 스케일 L1 구조적 희소성과 기울기 기반(테일러) 중요도는 선택 옵션으로, 1차의 가중치 절댓값 기준 균일 필터 가지치기는 비교 기준으로 남겼습니다. 1·2차의 고정 임계값과 학습형 임계값은 3차의 동적 조정으로 대체했습니다.

### [2-2 중간층 매칭 기반 지식 증류](../2_analysis_speed/2-2_knowledge_distillation/README.md)

- (1차) 지식 증류 기술 설계
- (2차) 중간 레이어 매칭을 활용한 지식 증류 구현
- (3차) 고도화된 중간층 매칭을 적용한 지식 증류

최종 구현은 로짓 증류, 가중 특징맵 매칭, 어텐션 맵 매칭(손실과 이득), GAN 기반 중간층 매칭을 합친 방법이고, 상위 계층의 교사가 하위 계층의 학생을 가르치는 연합 증류도 지원합니다. 1차의 소프트 라벨 혼합 손실과 다중 교사 앙상블, 2차의 레이어 중요도 가중 매칭과 적응형 학습률은 각각 단독 방법으로도 고를 수 있습니다.

### [2-3 MapReduce 기반 다계층 연합 분석](../2_analysis_speed/2-3_mapreduce_analysis/README.md)

- (1·2차) 다계층 FedATC, Transformer 압축
- (3차) MapReduce 기술을 활용한 효율적인 다계층 연합 분석

클라이언트, 그룹, 중앙으로 나뉜 구조와 블록 키값쌍, 표본 수 가중 Reduce, 개수·합·제곱합 통계 집계를 유지했습니다. 업데이트는 실제 Transformer 인코더로 압축한 잠재 표현과 주요 잔차만 보내고, 받는 쪽에서 복원해 Flower 집계에 넣습니다. INT8만 쓰던 이전 실행기는 따로 두지 않았습니다. zlib/XOR 무손실 전송과 직접 평균, shuffle 검산은 비교 기준으로 남겼습니다.

### [2-4 그래프 기반 동적 클러스터링 중복 제거](../2_analysis_speed/2-4_graph_deduplication/README.md)

- (1차) 유사도 기반 중복 분석 데이터 압축(SID)
- (2차) 동적 클러스터링 기반 중복 분석 제거(DCNI)
- (3차) 로컬 단말 구조의 연관성을 반영한 그래프 기반 동적 클러스터링 중복 제거

로컬 단말과 군집 중심으로 이루어진 그래프를 GraphSAGE로 학습하고, 데이터 요약이나 데이터량이 바뀌면 후보 그래프를 갱신합니다. 실제로 지우는 것은 SHA256과 배열이 모두 같은 사본뿐입니다. 해시 스케치만 쓰던 이전 실행기는 GraphSAGE 경로로 대체했고, 정적 그래프는 비교 조건으로 남겼습니다.

## 다. 단말/기관 간 불균일 데이터를 고려한 학습 모델 정확도 향상 기술

### [3-1 트랜스포머 기반 멀티모달 학습 모델](../3_heterogeneous_data/3-1_multimodal/README.md)

- (1차) 공동 임베딩 기반 멀티모달 피처 생성·연결
- (2차) 어텐션 기반 멀티모달 학습 모델과 연결
- (3차) 트랜스포머 기반 멀티모달 학습 모델

1차의 피처 생성은 최신 모델의 인코더와 공통 임베딩으로, 2차의 셀프 어텐션과 크로스 어텐션은 3차의 인코더-디코더 구조로 합쳤습니다. 1·2차에 완성한 모델은 재현용 기준선으로 분리했습니다. 계층적 피처 융합, 정규화 기반 정렬, 그래프 어텐션 연결은 대체됐다는 근거가 없어 별도 기능으로 남겼습니다.

### [3-2 연합학습 알고리즘 성능 평가 지표](../3_heterogeneous_data/3-2_fl_metrics/README.md)

- (3차) 연합학습 알고리즘 성능 평가 지표 개발

지표 16개를 공통 API로 제공합니다. 정밀도와 재현율 계산을 보고서 생성 코드에서 떼어 냈고, 실제 센서 조합, 입력 중단과 복귀, 송수신, 손상과 복원, 프라이버시 대조 실험은 유지했습니다. 관측하지 않은 값을 0이나 성공으로 채우지 않습니다.

### [3-3 데이터 불균형 해결](../3_heterogeneous_data/3-3_data_imbalance/README.md)

- (1차) 데이터 불균형 문제 해결 기술 설계

1차 설계 항목을 그대로 구현했습니다. 클라이언트별 SMOTE, Tomek Links, ENN 조합 샘플링과 데이터 양 및 로컬 손실에 따른 동적 가중치 집계가 들어 있고, 적용 전후의 로컬 성능과 전역 성능을 비교합니다. 후속 차년도에 대체 항목이 없어 유지했습니다.

## 계획과 구현이 다른 부분

- 1차 비교 환경 계획에 있던 의료, 소셜 미디어, 금융 데이터 수집은 MNIST와 합성 데이터 실험으로 대신했습니다. 해당 분야의 실제 데이터로 실증하지는 않았습니다.
- 지역 분산 비교에서 사이트는 한 호스트 안에서 논리적으로만 나뉩니다. 업데이트 암호화는 AES-GCM 업로드 보호와 쌍별 마스크 집계 시뮬레이션이며, 운영 환경의 TLS, 키 관리, 탈락 복구는 포함하지 않습니다.
- 계층형 시뮬레이터의 통신 지연과 대역폭은 네트워크 모델 위에서 계산한 가상 시간입니다. 학습과 메시지 바이트 수는 실제로 측정합니다.
- 멀티모달 모델의 정렬 코드와 그래프 연결 코드는 남아 있지만 Transformer 기본 순전파에는 연결되어 있지 않습니다.
