# 통합 모듈의 범위

공개 코드는 연구개발계획서의 아래 세 항목을 기능별로 통합한 구현
차년도별 복사본과 실행 경로를 두지 않으며, 최신 경로가 사용하는 공통 기술은 한 곳에서 재사용

## MapReduce 기술을 활용한 효율적인 다계층 연합 분석 기법 개발

- 클라이언트, 그룹, 중앙 서버를 연결하는 FedATC 구조 유지
- 블록별 키값쌍과 표본수 가중 Reduce를 사용하는 모델 집계 유지
- 모델 업데이트 외에도 개수, 합, 제곱합을 사용하는 통계 집계 유지
- 실제 Transformer 인코더로 압축한 잠재 표현과 주요 잔차를 전송하고, 수신 디코더가 복원한 업데이트를 Flower 집계에 반영
- INT8은 잠재 표현과 잔차의 부호화 및 무손실 대조군의 입력 표현으로 사용
- 순수 INT8만 적용하는 이전 실행기를 최종 제안 방식으로 중복 제공하지 않음

## 로컬 단말 구조의 연관성을 반영한 그래프 기반 동적 클러스터링 중복 제거 기술 개발

- 로컬 단말과 군집 중심으로 그래프를 구성하고 GraphSAGE로 연관성 학습
- 가중 이웃 샘플링, 풀링 집계, 정표본과 부정 표본 손실 최적화 유지
- 데이터 요약과 데이터량의 변화에 따른 후보 그래프 갱신 유지
- SID의 유사도 기반 중복 식별 방향을 후보 단말 선정에 반영
- 최종 삭제는 SHA256과 특징 및 레이블 배열의 일치 검증으로 확인한 사본에 한정
- 버전별 식별 정보와 후보 연결 관계에 따른 마스크 캐시 유지
- 중복 제거 이후 학습 스텝 변화에 대한 학습률 보정 유지
- 해시 스케치만으로 후보를 선택하는 이전 제안 실행기는 GraphSAGE 경로로 대체

## 연합 학습 알고리즘 성능 평가 지표 개발

- 16개 지표의 이름, 입력, 단위와 계산 결과를 공통 API로 제공
- 정밀도와 재현율 계산을 보고서 생성 코드에서 분리
- 실제 센서의 조합, 입력 중단 및 복귀, 로컬 모델과 전역 모델의 대조 실험 유지
- 실제 전송 프레임, 업데이트 손상과 복원, CPU 시간과 메모리 사용량의 검증 유지
- 프라이버시 예산 계산과 별도 회원추론 공격 대조 실험 유지
- 결측 측정이나 정의되지 않은 분모를 성공 또는 0으로 대체하지 않음

## 유지한 비교 기능

- 정적 그래프는 동적 갱신의 효과를 비교하기 위한 대조 조건
- 동일한 패킷 구조의 zlib, XOR 및 바이트 셔플 무손실 전송은 Transformer 압축의 비교 조건
- 잠재 표현을 사용하지 않는 잔차 대조는 압축기 구성 요소를 분석하기 위한 선택 조건
- 직접 가중 평균과 독립 shuffle 집계는 MapReduce 결과의 검산 경로

이 기능은 제안 방식의 구버전 배포본이 아니라 각 기술의 영향을 구분하는 데 필요한 비교 기능

## 적용 범위

Flower를 이용한 연구용 참조 구현이며, 기본 학습 경로는 단일 호스트의 논리 단말을 동기 실행
중복 검증은 동일 데이터 사본에 한정하며 의미가 유사한 서로 다른 데이터의 삭제를 주장하지 않음
응용 프레임의 전송량은 실제 네트워크의 TCP, TLS 및 재전송 비용과 구분
프라이버시 예산은 명시한 메커니즘과 공개 범위에만 적용하며 공격 AUC만으로 보호를 보장하지 않음
