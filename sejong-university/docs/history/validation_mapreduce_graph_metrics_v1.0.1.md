# 통합 공개 코드 검증

확인일 2026-11-02

## 기존 저장소용 세 모듈 배치 확인

v1.0.1은 기존 저장소의 `Federated_Learning` 아래에 실제 소스를 세 폴더로 나눈 배포 구성
학습과 집계 및 부호화 연산은 유지하고 패키지 경로, 설치 설정과 소스 해시의 파일 위치 해석을 수정

- 기존 기능 테스트와 분리된 소스 경로 검증을 포함한 총 37개 테스트 통과
- 세 모듈의 소스 파일 40개를 공통 매니페스트로 확인하고 경로 이탈 및 중복 구현 검사 적용
- 새 배치에서 compact 및 Transformer 방식을 각각 4라운드 실행하여 기존 구조와 모델, 예측, 제거 마스크, 전송량 및 학습량 일치
- 별도 폴더에 설치한 wheel에서 공개 모듈 39개 import와 주요 CLI 5개 실행 통과
- 분리된 원본 경로에서 저장한 두 실행을 설치된 패키지로 1,536회 독립 검산하여 통과
- 모듈 안으로 옮긴 시각화 노트북도 pipp의 Python 3.10에서 상위 작업 경로를 찾아 실행함을 확인

아래는 동일한 알고리즘을 통합하면서 확인한 학습 재현 및 송수신 검증 내역
원본 통합 배포본과 연구 결과는 보존하며 이번 배포에는 폴더 구조에 필요한 수정만 추가

## 실행 환경

- Windows, Python 3.12.14, CPU 실행
- Flower 1.22.0, NumPy 2.3.4, SciPy 1.16.2, scikit-learn 1.7.2, PyTorch 2.6.0+cpu
- 시각화 별도 확인은 기존 pipp의 Python 3.10.18, NumPy 1.26.4, SciPy 1.11.4, Matplotlib 3.7.5 사용

## 통과한 확인

- 단위 및 통합 테스트 35개 통과, 실패와 건너뛴 테스트 없음
- MapReduce 벡터 집계 110개 조건과 충분통계 집계 30개 조건 통과
- 직접 평균 대비 최대 절대 차이는 3.33 × 10^-16으로 확인
- 실제 GraphSAGE 가중치와 학습 손실, 후보 연결 관계, 캐시 무효화, 정확 일치 판정 및 고유 표본 보존 확인
- 수신 전 배포 필요 조건, 별도 수신 객체의 복원, 손상 프레임 및 잘못된 채널 거부, 학습 자료 해시 검증 확인
- 16개 지표의 알려진 정답, 목적별 대조 입력, 단위 분리 및 정의되지 않는 분모 처리 확인
- 전송 장부 변조와 허용하지 않은 시험 출력물을 독립 검증기가 탐지함을 확인

## 전체 압축기 학습 재현

공개 코드로 두 데이터셋과 세 개 수집 시드의 24라운드 학습을 수행하여 총 144라운드의 학습용 업데이트를 새로 수집
학습 전용 표본과 압축기 내부 검증용 시드를 분리한 상태로 기본 설정의 Transformer 학습을 수행

- 수집한 14,640개 블록의 값, 유효 길이, 역할, 데이터셋, 시드, 라운드, 단말, 업데이트 및 블록 식별 필드가 원본과 일치
- 기본 60 epoch 상한과 조기 종료 설정으로 학습한 45개 가중치 텐서가 기존 s2d8 모델과 모두 일치
- 수신용 내보내기는 학습 자료의 상세 메타데이터를 제외하면서 학습 가중치를 그대로 보존

새 내보내기 형식은 전송에 필요하지 않은 메타데이터를 정리하므로, 같은 가중치라도 과거 내보내기 파일과 배포 바이트 수가 달라질 수 있음
각 실행의 아티팩트 해시와 실제 배포량을 보존하여 비교하며 과거 보고서의 수치는 고정된 원본 실행 기록에 대응

## 기존 학습 결과와 대조

보존된 연구용 압축기 가중치를 읽기 전용으로 사용하여 두 데이터셋과 세 코덱의 80라운드 실행을 대조
시드 19001의 여섯 조건, 총 480라운드에서 아래 항목 일치

- 선택 모델과 마지막 모델
- 검증 및 시험 예측과 중복 제거 마스크
- 전체 전송량, 상향 전송량, 하향 전송량, 제어 정보와 배포 비용
- 처리 표본수, 학습 스텝, 체크포인트 선택 및 macro F1

이는 코드 통합에 따른 수치 회귀 확인이며 기존 전체 확인 실험의 통계 분석을 새로 수행한 결과와는 구분
원본 연구 결과와 보고서 파일은 변경하지 않음

## 실제 송수신과 독립 검산

- 목적별 시스템 평가에서 작업자 3개를 사용하는 TCP 및 Flower 실행을 5라운드씩 두 차례 수행
- 독립 검증기로 프레임 93개, 수신 업데이트 30개와 라운드 모델 10개를 재계산하여 통과
- Transformer 및 compact 전송도 두 데이터셋에서 각각 4라운드의 TCP 실행과 기본 실행을 대조하여 네 조건 모두 통과
- 별도 프로세스에서 실제 수신 복원한 배열이 그룹과 중앙 Flower 집계에 반영됨을 확인
- TCP 검증 경로의 모델, 검증 예측, 제거 마스크와 연구용 전송량이 기본 경로와 일치
- RPC 응답 배열과 검증용 봉투의 비용은 모델 전송량과 별도 기록

짧은 신규 파이프라인도 학습용 수집, 압축기 학습, 내보내기, 두 데이터셋의 네 방식 비교까지 실행
8개 실행의 전송 장부와 저장 모델을 독립 검증기로 6,136회 확인하여 통과
이 짧은 실행에서는 시험 예측을 수행하지 않았으며 전체 성능 평가를 대신하지 않음

## 설치와 배포

- wheel 빌드와 별도 폴더 설치 통과
- 설치 경로의 공개 모듈 38개 import와 주요 CLI 6개 실행 통과
- 목적별 실험 CLI 13개의 도움말 실행 통과
- 설치한 패키지에서 원본 프로젝트 소스 경로 없이 저장 결과 검증 통과
- 기존 의존성을 사용하는 오프라인 설치를 확인했으며 새 운영체제의 네트워크 의존성 설치까지 수행한 것은 아님
- 기본 Matplotlib 노트북을 pipp의 Python 3.10에서 실행하고 그림 배치 확인
- 배포 ZIP은 소스와 문서의 허용 목록으로 작성하고, 파일별 SHA256과 ZIP 내용 대조 수행

전체 HAR 학습과 새 Gaussian 잡음 기반 프라이버시 실험은 이번 코드 통합 과정에서 반복하지 않음
해당 실험의 실행 및 검증 코드는 유지하며 기존 완료 결과는 원본 위치에 보존
