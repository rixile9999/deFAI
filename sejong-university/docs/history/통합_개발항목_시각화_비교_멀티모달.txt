정리 원칙
- 연차별 제목을 병렬로 나열하지 않고, 후속 차년도에서 구체화된 기능을 하나의 최종 개발 항목으로 정리했다.
- 이전 차년도의 독립 기능은 후속 문서에 이름이 없다는 이유만으로 삭제하지 않았다.
- 동일 목적의 설계와 구현은 최신 구현 항목으로 통합했다. 서로 다른 알고리즘의 수학적 동등성이나 우월성을 의미하지 않는다.
- 아래 목록은 개발 범위의 통합본이다. PDF의 계획 문구 자체를 구현 완료 증거로 사용하지 않으며, 실제 코드와 다른 부분은 마지막에 구분했다.

1. 계층형 연합학습 평가 시각화 도구
(1) 계층형 연합학습의 성능 평가 및 매칭 환경 모니터링 모듈

- 연합학습 알고리즘 성능 비교 및 학습 과정 시각화
  ‣ FedAvg, FedProx, q-FedAvg의 학습 성능을 비교하고 글로벌 모델과 클라이언트의 학습 진행 상황을 평가
  ‣ Training trend와 outlier detection을 활용해 학습 추세 및 이상 징후를 확인하고 클라이언트 학습 과정 비교 지원
- 계층 구조 및 매칭 알고리즘 평가 시각화
  ‣ 중앙 서버, 엣지 서버, 클라이언트의 계층적 학습 환경을 tree로 표현
  ‣ 우선순위 rank, 매칭 행렬, 매칭 과정의 training trend와 outlier detection을 통해 매칭 상태와 변화 분석
- 통신 환경, 자원 및 실행 기록 모니터링
  ‣ Hyperbolic으로 통신 연결 구조를 표현하고 pixel-based 및 parallel 시각화로 서버 통신 상태 비교
  ‣ Sankey로 네트워크 트래픽을 나타내고 CPU 및 메모리 사용량을 range line과 line으로 제공
  ‣ Sparklines table을 활용해 클라이언트별 실행 기록과 상태 변화 확인
- 데이터 분포 및 모델 관계 분석
  ‣ 클라이언트별 데이터 비율과 정보 엔트로피를 heatmap으로 표현
  ‣ Pareto, stream, dendrogram, sociogram, matrix를 활용해 기여도 및 모델 간 관계 분석
  ‣ 시뮬레이션 설정과 Flask 기반 웹 연동을 통해 평가 결과를 갱신하는 시각화 모듈 제공
⇨ 계층형 연합학습의 성능, 매칭, 데이터 및 통신 상태를 함께 분석하는 시각화 모듈로 알고리즘 평가와 학습 환경 진단 지원

통합 판단
- 1차년도 단일 컴퓨터 성능 모니터링 설계와 2차년도 시뮬레이션 모니터링 구현은 3차년도 계층형 환경 평가 모듈의 기반으로 통합했다.
- 학습 추세와 이상치 탐지는 하나의 기능군으로 묶되, 글로벌 학습과 매칭 과정이라는 서로 다른 적용 대상은 유지했다.
- Tree는 계층 구조, hyperbolic은 통신 연결, sankey는 트래픽 흐름을 나타내므로 서로 대체하지 않았다.
- 1차년도 리소스, 로그, 모델 관계 시각화와 2차년도 데이터 비율 및 엔트로피는 독립 기능으로 유지했다.
근거: 1차년도 인쇄 36~37쪽(PDF 2~3쪽), 2차년도 인쇄 58쪽(PDF 2쪽), 3차년도 인쇄 81쪽(PDF 2쪽).

2. 지역 분산 컴퓨팅과 연합 컴퓨팅 비교 모듈
(1) 시뮬레이션 기반 지역분산 및 연합 컴퓨팅 비교 환경 구현 및 평가

- 데이터 준비 및 전처리 파이프라인
  ‣ 학습용 데이터와 평가용 데이터를 분리하고 사이트별 분산 데이터 구성
  ‣ 데이터 정제, 정규화, 특징 추출을 연속된 전처리 과정으로 통합
- 지역 분산 및 연합 컴퓨팅 시뮬레이션
  ‣ 지역 분산 환경에서는 로컬 서버별 독립 학습과 분석 결과 공유, 데이터 재분할 및 동기화, 중앙 분석 방식을 비교
  ‣ 연합 환경에서는 원본 데이터를 로컬에 유지한 상태로 각 장치가 학습하고, 중앙 서버가 모델 업데이트를 집계해 글로벌 모델 생성
  ‣ 글로벌 모델의 전체 데이터에 대한 분석 성능과 사이트별 로컬 분석 성능을 함께 평가
- 모델 업데이트 보호와 통신 비용 비교
  ‣ 암호화 및 차분 프라이버시 적용 조건을 설정하고 모델 업데이트 보호에 따른 성능과 통신량 변화 확인
  ‣ 원 데이터 이동량, 모델 및 통계 전송량, 통신에 필요한 시간을 구분해 환경별 비용 비교
- 공통 평가 및 결과 시각화
  ‣ 정밀도, 재현율, F1을 공통 평가 기준으로 계산하고 로컬 및 글로벌 성능 비교
  ‣ 비교 조건과 분석 결과를 기록하고, 사용자 선택 지표에 따라 성능 비교 및 진행 상황을 실시간으로 갱신
⇨ 데이터 처리 방식과 모델 학습 구조가 다른 두 컴퓨팅 환경을 공통 평가 절차로 비교하는 모듈로 성능과 데이터 이동 비용을 고려한 환경 선택 지원

통합 판단
- 1차년도 데이터 준비, 독립 로컬 분석 및 지표 설계는 3차년도 전처리, 시뮬레이션, 로컬 및 글로벌 평가 구현으로 통합했다.
- 1차년도 독립 분석 시나리오의 데이터 비이동 조건은 유지하되, 3차년도에는 결과 공유와 데이터 이동 및 동기화 시나리오까지 비교 범위를 확장했다.
- 클라이언트 간 통신 차단을 모든 지역 분산 환경의 공통 조건으로 적용하지 않았다. 독립 시나리오에서의 로컬 학습 조건과 시나리오별 전송 정책으로 구분했다.
- 사용자 지정 통합 범위에 비교 모듈의 2차년도 항목은 없으므로 별도 연차 항목을 추가하지 않았다.
- 결과 시각화는 첫 번째 작업 공간의 비교 카드를 재사용하며 별도 대시보드를 중복 구현하지 않았다.
근거: 1차년도 인쇄 36쪽(PDF 2쪽), 3차년도 인쇄 81~82쪽(PDF 2~3쪽).

3. Transformer 기반 멀티모달 학습 모델
(1) 공통 임베딩과 크로스모달 상호작용을 통합한 Transformer 학습 모델

- 모달리티별 특징 추출 및 공통 임베딩
  ‣ 이미지 CNN, 텍스트 Transformer, 오디오의 컨볼루션 및 순환 신경망으로 모달리티별 특징 추출
  ‣ 각 특징을 공통 임베딩 공간으로 사상하고 차원을 축소해 모달리티 간 비교와 결합을 위한 표현 생성
- 모달리티 임베딩 통합 및 Transformer 인코딩
  ‣ 모달리티 중요도를 반영하는 학습가능 가중합으로 인코더 출력을 통합
  ‣ 입력 임베딩과 모달리티별 위치 인코딩을 구성하고 멀티헤드 어텐션으로 시퀀스 의존성 학습
  ‣ Position-wise feed-forward 연산으로 특징 표현의 비선형 변환 수행
- 크로스모달 상호작용 및 특징 융합
  ‣ 타겟 모달리티를 Query, 소스 모달리티를 Key와 Value로 사용하는 크로스모달 Transformer 디코더로 상호작용 학습
  ‣ 게이트형 멀티모달 융합(GMU)을 통해 모달리티별 정보를 통합하고 최종 예측에 반영
  ‣ 저수준 및 고수준 특징을 결합하는 계층적 피처 융합은 보완 기능으로 유지
  ‣ 예측 확률 및 표현 벡터를 출력하고, 선택형 자기회귀 디코더를 통해 생성 시퀀스 출력 지원
- 모달리티 정렬 및 그래프 연결 기능
  ‣ 크로스모달 어텐션 행렬과 정규화를 활용해 모달리티 간 유사도 평가 및 정렬 수행
  ‣ 모달리티를 노드로, 상호 연관성을 엣지로 표현하는 그래프 어텐션 연결 기능 유지
  ‣ 정렬 및 그래프 연결은 3차년도 디코더와 역할이 다른 독립 모듈로 관리하고, 최신 모델의 기본 순전파에 자동 포함된 것으로 기술하지 않음
⇨ 공통 임베딩, Transformer 인코딩 및 크로스모달 융합을 결합한 학습 모델로 서로 다른 모달리티의 특징과 상호작용을 활용하는 통합 예측 지원

통합 판단
- 1차년도 피처 생성은 최신 모델의 인코더와 공통 임베딩 기반으로 유지했다.
- 1차년도 동적 중요도 조절, 2차년도 셀프어텐션 및 크로스어텐션, 3차년도 임베딩 통합 및 인코더-디코더를 하나의 최신 학습 구조로 설명했다.
- 초기 코어텐션 모델은 동일 연산으로 간주해 삭제하지 않고 이전 완성 모델과 함께 재현용 기준선으로 분리했다. 기본 학습 대상은 3차년도 Transformer 하나다.
- 계층적 피처 융합, 정규화 기반 정렬 및 그래프 어텐션 연결은 최신 구조로 완전히 대체되었다는 근거가 없어 별도 기능으로 유지했다.
- FedATC, 분석 결과 압축, 모델 경량화, 지식 증류 등은 사용자가 지정한 세 번째 항목의 연차별 세부 목록과 별개의 개발 항목이다. 관련 코드는 보조 실험으로 보존하되 이번 통합 개발 목록의 핵심 항목에 포함하지 않았다.
근거: 1차년도 인쇄 46~47쪽(PDF 8~9쪽), 2차년도 인쇄 69~70쪽(PDF 9~10쪽), 3차년도 인쇄 91~92쪽(PDF 7~8쪽).

계획과 구현의 구분
- 1차년도 비교 환경 계획의 의료, 사회 미디어, 금융 데이터 수집은 현재 MNIST 및 합성 데이터 실험으로 실증되었다고 볼 수 없다.
- 로컬 데이터베이스 저장 및 네트워크 수준의 통신 차단은 현재 JSON 결과 저장과 단일 호스트의 논리적 사이트 분리와 다르다. 실제 DB 및 네트워크 차단 구현으로 표기하지 않았다.
- 업데이트 암호화는 AES-GCM 업로드 보호이며, 쌍별 마스크 집계는 시뮬레이션이다. 운영 환경의 TLS, 키 관리 또는 탈락 복구까지 포함하지 않는다.
- 계층형 시뮬레이션과 물리적으로 분산된 다중 호스트 실행의 성능 증명은 구분한다.
- 그래프 연결과 정규화 기반 정렬 코드는 남겼지만 최신 Transformer 기본 경로에 연결되어 있지 않다. 선택형 구성으로 통합 학습했다는 주장을 추가하지 않았다.
- 기존 실험 결과는 evidence 아래에 보존했다. 작업 공간 분리 검증을 새로운 정확도 개선 실험으로 해석하지 않는다.

작업 공간 구성
01_visualization: 시각화 모듈, 계층형 시뮬레이션, 매칭 및 외부 연동
02_comparison: 지역 분산 및 연합 환경, 모델 업데이트 보호, 비교 실행
03_multimodal: 최신 Transformer, 인코더, 임베딩, 융합, 정렬 및 재현용 기준선
shared: 데이터, 전처리, 평가 지표, 리소스 수집, 공통 Flower 학습 및 집계
tests: 세 작업 공간 사이의 연동을 포함한 회귀 검증

기존 로컬 원본 작업 공간은 이전 작업과 결과를 보존하기 위해 그대로 두었다.
이 통합본은 원본 코드 경로를 실행 의존성으로 사용하지 않는 별도 작업본이다.
세 폴더와 shared는 함께 유지하며, 각 workspace.code-workspace를 VS Code로 열어 작업한다.
