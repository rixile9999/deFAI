# UDT-Java provenance

Source: https://github.com/JohannesBuchner/udt-java
Commit: `99a585aa5b4036b8a0406ff5f3e3675e64ef6508`
Original authors: Forschungszentrum Juelich / Bernd Schuller and contributors.
The original license and source notices are retained in `vendor/udt-java`.
`upstream_hashes.json` records unmodified upstream file hashes.

Local patches are limited to interruption propagation, stable handshake sequence
numbers, handshake retry session reuse and lifecycle cleanup. They are recorded
in Git independently of the upstream snapshot. This is a research integration,
not a new implementation of the underlying UDT protocol.
