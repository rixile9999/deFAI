# 단일 레이어 HbA1c 예측 연합학습

가장 간단한 형태의 연합학습 시스템입니다. 레이어 1개, 노드 1개로 구성되어 있어 연합학습의 기본 개념을 쉽게 이해할 수 있습니다.

## 🏗️ 구조

### 모델 구조
- **입력**: 2개 (혈당, 체중)
- **레이어**: 1개 (Dense layer)
- **노드**: 1개
- **출력**: 1개 (HbA1c 예측값)

### 파라미터
- **가중치**: 2개 (w1, w2)
- **편향**: 1개 (b)
- **총 파라미터**: 3개

## 📁 파일 구조

```
simple_single_layer/
├── simple_server.py              # Python Flask 서버
├── src/main/kotlin/dev/flower/
│   ├── SimpleSingleLayerClient.kt    # Kotlin 클라이언트
│   └── SimpleSingleLayerClientMain.kt # 메인 실행 클래스
├── build.gradle.kts              # Kotlin 프로젝트 설정
├── run_server.sh                 # 서버 실행 스크립트
├── run_client.sh                 # 클라이언트 실행 스크립트
├── saved_models/                 # 저장된 모델 파라미터
└── README.md                     # 이 파일
```

## 🚀 실행 방법

### 1. 서버 실행

```bash
./run_server.sh
```

서버가 포트 1501에서 실행됩니다.

### 2. 클라이언트 실행

```bash
./run_client.sh
```

클라이언트가 서버에 연결하여 연합학습을 수행합니다.

## 🔧 기술 스택

### 서버 (Python)
- **Flask**: HTTP 서버
- **TensorFlow**: 딥러닝 프레임워크
- **NumPy**: 수치 계산

### 클라이언트 (Kotlin)
- **OkHttp**: HTTP 클라이언트
- **Gson**: JSON 직렬화
- **Kotlin Coroutines**: 비동기 처리

## 📊 연합학습 과정

1. **초기화**: 서버가 글로벌 모델 파라미터 초기화
2. **파라미터 전송**: 서버가 클라이언트에 현재 파라미터 전송
3. **로컬 훈련**: 클라이언트가 로컬 데이터로 모델 훈련
4. **파라미터 제출**: 클라이언트가 업데이트된 파라미터를 서버에 제출
5. **집계**: 서버가 모든 클라이언트의 파라미터를 평균으로 집계
6. **반복**: 2-5단계를 여러 라운드 반복

## 🎯 특징

- **단순성**: 레이어 1개, 노드 1개로 가장 간단한 구조
- **이해하기 쉬움**: 연합학습의 핵심 개념을 명확하게 보여줌
- **디버깅 용이**: 파라미터가 3개뿐이라 문제 발생 시 추적하기 쉬움
- **교육용**: 연합학습 입문자에게 적합

## 📈 예상 결과

- **파라미터 수**: 3개 (가중치 2개 + 편향 1개)
- **훈련 시간**: 매우 빠름 (단순한 구조)
- **메모리 사용량**: 최소
- **학습 곡선**: 단순한 선형 관계로 안정적인 수렴
