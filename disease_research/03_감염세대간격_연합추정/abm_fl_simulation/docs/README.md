# ABM 기반 연합학습 확장 — 연합 세대간격(GI) 추정

감염주기 연구(H:\Work\감염주기_연구, 코로나19 세대간격의 Burr XII 분포 적합)를
**에이전트 기반 모형(ABM) 기반 연합학습(Federated Learning)** 으로 확장한 작업 디렉토리.

## 1. 확장 배경 — 왜 이 조합인가

| 출처 | 근거 |
|---|---|
| 감염주기 논문 §5.5.1 | 세대간격은 병원체 상수가 아니라 **방역체계(검사·격리)의 산물** → 국가·시기·지역별 **사이트 로컬 추정**이 필요 |
| 감염주기 논문 §5.2 | 데이터가 이미 6개 축 51개 층(17개 시도 포함)으로 층화 → **연합 단위가 자연 존재** |
| 감염쌍 데이터 특성 | 감염자→피감염자 연결(접촉추적)은 **최고 민감도 개인정보** → 원본 비공개 강제 조건 |
| 본 프로젝트(pandemic_model_FL-causal) 목표 | **보안 강화**: 원본을 모으지 않고 분석. 기존 MLP 확장은 Tier 1 복호화로 blind 속성이 깨졌음 |

**핵심 설계 통찰**: Burr XII 최대우도의 로그우도·그래디언트는 **표본별 합** —
즉 지역별 기여분의 **덧셈만으로** 전국 추정이 완성된다. 덧셈만 필요하므로
가산 동형암호(Paillier/CKKS)로 **Tier 1(시도)이 내용을 못 본 채 합산**하는
blind aggregation이 그대로 성립한다. (MLP/FedAdam 확장에서 잃었던 성질의 복원)

## 2. 3-tier 연합 프로토콜

```
Tier 2 (시군구, 244개): 자기 감염쌍 T 보유(원본 비공개)
    → 라운드마다 현재 θ에서 (ℓ_d, ∇ℓ_d) 4개 숫자 계산 → 공개키 암호화
Tier 1 (시도, 17개): 암호문 동형 덧셈만 (복호화 불가 = blind)
Tier 0 (중앙): 비밀키로 합산값만 복호화 → L-BFGS로 θ 갱신 → 재배포
수렴(~15-40라운드) 시 전국 풀링 MLE와 수학적으로 동일한 추정치 획득
```

전송량: 시군구당 라운드마다 **32바이트(float64 4개)** — 원본 수만 건 대비 무시 가능.

## 4. ABM 쪽 확인된 사실 (판독 근거)

- 정본: `H:\Work\KOR_CDC2025\abm_code-rev30\abm_simulation_rev31_timescale.py` (2,533줄, M5 포함 최신)
- 에이전트 256만 명(한국 5.26% 표본), 실제 5자리 시군구 코드 244개, 장소 기반 접촉
- 감염자ID·노출시각·발현시각·변이가 **영구 배열**(회복해도 보존) → 감염쌍 완전 복원 가능
- `save_gen_interval()`이 쌍 로그 CSV를 쓰며, 시군구·연령은 같은 함수에서 조인 가능 → [FL-EXT] 패치
- 주의(논문 §5.6): 이 ABM은 포화 레짐 + 교통수단 완전혼합 인공물 보유 → **절대값 인용 불가**,
  방법론 검증(추정기 간 상대 비교)에만 사용. 본 확장의 E1–E3는 전부 상대 비교라 유효.

## 5. 기초 확인 연구 성공 기준

| 실험 | 검증 내용 | 기준 |
|---|---|---|
| E0 | 패치 ABM이 시군구 컬럼 포함 쌍 로그 생산 | ≥200개 구, T>0 표본 충분 |
| E1 | 연합 추정 = 중앙집중 풀링 MLE | 표본당 NLL 차 < 1e-6, 모수 상대차 < 0.5% |
| E2 | 시도 blind 합산(평문·Paillier) 무손실 | 평문 < 1e-12, 동형 < 1e-5, 동형-전용 적합 < 1e-6 |
| E3 | 격리 대비 연합 이득 | 격리 실패율·모수 산포 정량 보고 |
