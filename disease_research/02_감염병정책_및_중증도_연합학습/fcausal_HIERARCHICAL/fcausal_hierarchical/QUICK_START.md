# ⚡ 빠른 시작 가이드

## 🎯 가장 간단한 방법 (추천)

### `demo_simple.bat` 사용 (pywin32 불필요)

1. **더블클릭**: `demo_simple.bat`
2. **대기**: 7개 터미널 창이 자동으로 열림
3. **수동 배치**: 창들을 3x3 격자로 배치
4. **완료**: Enter 누르면 시각화 영상 재생

---

## 📺 창 배치 가이드 (4K: 3840x2160)

```
┌───────────┬───────────┬───────────┐
│  (여백)   │   KDCA    │ Seongnam  │  ← 상단
│           │  Tier 0   │  Tier 2   │
├───────────┼───────────┼───────────┤
│   Seoul   │  (여백)   │ Gyeonggi  │  ← 중단
│  Tier 1   │           │  Tier 1   │
├───────────┼───────────┼───────────┤
│  Gangnam  │  Seocho   │   Suwon   │  ← 하단
│  Tier 2   │  Tier 2   │  Tier 2   │
└───────────┴───────────┴───────────┘
```

### 빠른 배치 방법 (Windows 스냅 기능)

1. **KDCA** 창 선택 → `Win + ↑` (상단 중앙)
2. **Seoul** 창 선택 → `Win + ←` (좌측 중단)
3. **Gyeonggi** 창 선택 → `Win + →` (우측 중단)
4. 나머지 창들도 드래그로 배치

## 🚀 실행 순서

### 1단계: 터미널 실행 (자동)

```
demo_simple.bat 실행
→ 7개 창 자동 오픈 (2-3초 간격)
```

### 2단계: 수동 배치 (30초)

- 각 창을 드래그하여 3x3 격자에 배치
- 각 셀 크기: 약 1280x720

### 3단계: 녹화 시작

- OBS Studio에서 Display Capture
- 연합학습이 자동으로 진행됨

### 4단계: 시각화 재생 (자동)

- Enter 누르면 `demo1_hierarchical.mp4` 재생
- 10초 영상

## 💡 Windows 창 스냅 단축키

- `Win + ←` : 왼쪽 절반
- `Win + →` : 오른쪽 절반
- `Win + ↑` : 최대화
- `Win + ↓` : 최소화/복원

### 격자 배치 팁:

1. 먼저 3개 열로 나누기 (각 1280px)
2. 그 다음 각 열을 3개 행으로 나누기 (각 720px)
3. 총 9칸 중 7칸 사용 (2칸 여백)

## ⚠️ 문제 해결

### 창이 너무 많아서 헷갈려요

**해결**: 창 제목으로 구분하세요
- `Tier 0 - KDCA`
- `Tier 1 - Seoul`
- `Tier 1 - Gyeonggi`
- `Tier 2 - Gangnam`
- `Tier 2 - Seocho`
- `Tier 2 - Suwon`
- `Tier 2 - Seongnam`

### Tier 0가 대기만 해요

**원인**: Tier 1 서버 2개가 연결되지 않음

**해결**:
1. Seoul 창 확인 (9001 포트)
2. Gyeonggi 창 확인 (9002 포트)
3. 두 창 모두 "Waiting for 2 districts..." 표시 확인

### 시각화 영상이 없어요

**해결**:
```bash
python demo1_hierarchical_visualization.py
```
