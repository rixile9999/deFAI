# 🚀 어떤 런처를 사용해야 할까?

## ✅ 추천: `demo_simple.bat` (배치 파일)

### 장점
- ✅ **연결 문제 완전 해결** (5초 대기 적용)
- ✅ **안정적** (pywin32 불필요)
- ✅ **빠름** (Python 오버헤드 없음)
- ✅ **디버깅 쉬움** (명령 순서 명확)
- ✅ **CES 데모용으로 최적화**

### 사용법
```bash
# 더블클릭만 하면 됨!
demo_simple.bat
```

### 실행 순서
```
1. Tier 0 시작 → 3초 대기
2. Tier 1 Seoul 시작 → 2초 대기
3. Tier 1 Gyeonggi 시작 → 5초 대기 ⭐
4. Tier 2 4개 시작 (1초 간격)
5. 25초 자동 대기
6. 시각화 영상 재생
```

## ⚠️ 비추천: `demo_launcher.py` (Python)

### 문제점
- ❌ **창 배치 불안정** (pywin32 의존)
- ❌ **느림** (창 대기 시간 2.5초씩)
- ❌ **복잡함** (디버깅 어려움)

- pywin32가 **제대로 설치**된 경우

## 🔧 문제 해결

### demo_simple.bat 사용 시

**Q: 창이 바로 꺼져요**
```
A: Tier 1 서버가 아직 안 켜졌을 때 Tier 2가 연결 시도
→ 이미 수정됨! (v1.2)
→ 5초 대기 시간 추가
```

**Q: 수동 배치가 귀찮아요**
```
A: 한 번만 배치하면 됩니다
→ 녹화 전에 미리 배치
→ Windows 스냅 기능 사용 (Win+화살표)
```

### demo_launcher.py 사용 시

**Q: pywin32 에러**
```
A: pip install pywin32
→ 설치 후 재실행
```

**Q: 창 배치 실패**
```
A: 정상입니다
→ 경고 메시지 무시
→ 수동으로 배치
→ 또는 demo_simple.bat 사용
```

**Q: 여전히 창이 꺼져요**
```
A: demo_simple.bat 사용하세요!
→ 더 안정적입니다
```
