## 🏛️ 계층 구조 상세

### Tier 0: 중앙정부 (KDCA)
- **보유 키**: Secret key (유일하게 복호화 가능)
- **역할**: 광역 집계 결과 복호화 및 DiD 분석
- **포트**: 8080
- **실행**: `python run_tier0.py`

### Tier 1: 광역지자체
- **보유 키**: Public key (암호화/합산만 가능, 복호화 불가!)
- **역할**: 
  1. Server 모드: 산하 시군구 데이터 수집
  2. 동형암호 합산 (내용을 모른 채)
  3. Client 모드: 중앙으로 집계 결과 전송
- **예시**:
  - 서울시: `python run_tier1.py --port 9001 --region Seoul --treated`
  - 경기도: `python run_tier1.py --port 9002 --region Gyeonggi`

### Tier 2: 기초지자체
- **보유 키**: Public key
- **역할**:
  1. 실제 환자 데이터 보유
  2. 메타 분석 통계 계산
  3. 암호화 후 상위 전송
- **예시**:
  - 강남구: `python run_tier2.py --data data/districts/seoul_gangnam.xlsx --target 127.0.0.1:9001`
  - 수원시: `python run_tier2.py --data data/districts/gyeonggi_suwon.xlsx --target 127.0.0.1:9002`

## 🔐 보안 특성

### Privacy-Preserving Aggregation

1. **시군구 → 시도**
   - 암호화된 통계 전송
   - 시도는 **내용을 볼 수 없음** (Public key만 보유)
   - Homomorphic Addition으로 합산만 수행

2. **시도 → 중앙**
   - 집계된 암호문 전송
   - 중앙은 **시도 단위 집계만 복호화**
   - 개별 시군구 데이터는 여전히 모름

### 정보 노출 수준

| 주체 | 알 수 있는 정보 | 모르는 정보 |
|------|---------------|------------|
| 시군구 (Tier 2) | 자기 지역만 | 다른 지역 |
| 시도 (Tier 1) | 없음 (암호문만) | 모든 내용 |
| 중앙 (Tier 0) | 시도 집계 | 시군구별 개별 데이터 |

**결론**: 중앙정부도 시군구별 세부 데이터는 알 수 없음! ✅

## 🚀 빠른 실행 (4단계)

### 1. 데이터 생성
```bash
tar -xzf fcausal_HIERARCHICAL.tar.gz
cd fcausal_hierarchical
python data_gen_hierarchical.py
```

**결과**: `data/districts/`에 9개 파일 생성
- 서울: gangnam, seocho, jongno
- 경기: suwon, seongnam, yongin  
- 부산: haeundae, saha, dongnae

### 2. 설정
```bash
python verify_hierarchical_data.py  # 검증
python setup_hierarchical.py        # 키 생성
```

### 3. 실행 (최소 4개 터미널)

#### Terminal 1: Tier 0
```bash
python run_tier0.py
```

#### Terminal 2: Tier 1 - Seoul
```bash
python run_tier1.py --port 9001 --region Seoul --treated --min-districts 2
```

#### Terminal 3: Tier 2 - Gangnam
```bash
python run_tier2.py --data data/districts/seoul_gangnam.xlsx --target 127.0.0.1:9001
```

#### Terminal 4: Tier 2 - Seocho
```bash
python run_tier2.py --data data/districts/seoul_seocho.xlsx --target 127.0.0.1:9001
```

## 🔬 기술적 특징

### 1. 동형암호 (Homomorphic Encryption)
```python
# Tier 1에서
encrypted_sum = encrypted_A + encrypted_B  # 복호화 없이 덧셈!
```

### 2. 메타 분석 (Meta-Analysis)
```python
# 각 지역이 전송하는 통계
[treated, n_pre, mean_pre, std_pre, n_post, mean_post, std_post]
```

### 3. 가중 평균 (Weighted Average)
```python
# Tier 0에서 Control group 집계
control_avg = Σ(value_i * weight_i) / Σ(weight_i)
```

## ⚠️ 주의사항

### 1. Tier 1 실행 순서
- **반드시 Tier 0 먼저 시작!**
- Tier 1은 서버 모드 완료 후 클라이언트 모드로 전환
- `--min-districts` 숫자만큼 Tier 2 접속 필요

### 2. 암호화
- 현재 버그 가능성 있음
- Plaintext 테스트: `--plaintext` 옵션 사용

### 3. 데이터 요구사항
- 최소 2개 광역 (Treatment + Control)
- 각 광역당 최소 1개 시군구
