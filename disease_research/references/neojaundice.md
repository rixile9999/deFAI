# NeoJaundice public source

Wang et al., NeoJaundice: Neonatal Jaundice Evaluation in Demographic Images,
Figshare version 1, published 2023-08-18.

- Dataset: https://doi.org/10.6084/m9.figshare.22302559.v1
- Official landing page: https://springernature.figshare.com/articles/dataset/22302559
- Official metadata: https://api.figshare.com/v2/articles/22302559
- Archive: https://ndownloader.figshare.com/files/39672982 (NeoJaundice.zip)
- Official license: CC0, https://creativecommons.org/publicdomain/zero/1.0/
- Official archive size: 461,702,440 bytes; MD5: 7330ef5106eeff4099b072f4d98d96b6.

On 2026-10-29 the local archive matched the official size and MD5. The extracted
local metadata.csv contains 2,235 image rows and 745 distinct patient identifiers,
matching the official dataset description. Its SHA-256 is
13b012ec0d1505a5a17a995dc7f9d3325bbad4ff893d38ec3702c646bade5af6.
The metadata table is a local extraction and is not claimed to be an original
archive entry. No photographs or participant-level metadata are republished here.

The official description reports a 12.9 mg/dL bilirubin threshold for initial
binary labels followed by pediatrician confirmation. This is dataset annotation
provenance, not a treatment recommendation. The GAN study audits and filters the
local extraction before partitioning; its retained sample count may differ.
